# Decisions

**Modular monolith, not microservices.** One FastAPI app with a `services/` layer keeps the 3–4 day scope honest while still separating concerns; the worker imports the same handlers.

**Job state in MongoDB, execution in Celery or inline.** Persisting jobs ourselves (instead of relying on the broker) gives idempotency keys, visible attempts/errors, admin retry and startup recovery regardless of backend. `JOB_BACKEND=inline` makes local setup and single-process deployment possible without Redis; Celery is a configuration switch.

**Local embeddings (MiniLM) instead of an embedding API.** Zero cost, no rate limits, fast enough for study material, and the model call budget goes to generation. Trade-off: weaker retrieval on very technical corpora; the threshold is configurable and evaluated.

**Qdrant with a strict payload filter on every query.** Isolation must not depend on the model or the prompt. `user_id` + `project_id` are in every point payload and every filter; a second check happens on the returned payloads.

**Citations are built by the server.** The model only returns chunk ids; label, page and snippet come from our records. This removes fabricated sources by design rather than by instruction.

**Visuals as typed specs rendered deterministically.** Letting the model emit SVG/HTML would be an injection and quality risk. A small vocabulary of diagram kinds covers the common study visuals (sequences, layers, steps, arrays, networks, curves, joins, trees) and is trivially escapable and testable. The learner's own figures always take priority.

**Mastery as evidence-weighted EWMA with history.** Simple, explainable and unit-testable. Bayesian knowledge tracing would be the next step; the history table makes that migration possible without losing data.

**Adaptive policy is rule-based and documented.** A model-chosen policy would be opaque; the weighted-priority rule and two-result band shift are transparent to the learner (the UI shows the selection reason).

**Firebase Auth with a dev bypass.** Firebase gives real email/Google auth in minutes; `AUTH_MODE=dev` (loudly warned at startup) removes the setup barrier for local runs and tests. Identity is still never taken from request bodies.

**No streaming (yet).** Structured JSON output lets citations and visuals be validated before anything is shown. Streaming the answer field while validating at the end is a follow-up.

**Recommendations generated by workflow, not on read.** Generating after each quiz keeps reads fast, makes the trigger explicit and idempotent, and stores the evidence trail; a manual refresh exists for control.

**One PDF only.** Scope. The pipeline is structured so `extract_pdf` could be swapped per file type.

**Tailwind without a component library.** Fewer moving parts for the candidate build; the small `ui.tsx` kit keeps the UI consistent.
